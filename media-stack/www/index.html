Один адрес в браузере: — сервисы на префиксах /prowlarr/, /transmission/, /jellyfin/ (локально обычно http://, на сервере — https://).
Один раз настройте приложения: Jellyfin — Base URL /jellyfin; Prowlarr — URL Base /prowlarr. Иначе интерфейсы соберут не те пути.
Prowlarr → Transmission (внутри Docker): хост transmission, порт 9091, логин/пароль из .env, при необходимости URL Base /transmission/.
Доступ по имени домена: добавьте домен в TRANSMISSION_HOST_WHITELIST в .env, чтобы не резало RPC.
